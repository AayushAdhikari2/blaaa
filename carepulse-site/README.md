# Carepulse Landing Page

A static, responsive SaaS landing page for a healthcare data platform. Plain HTML, CSS and JavaScript. No build step.

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Push these files to a GitHub repo.
2. Go to Settings > Pages.
3. Under "Branch", choose `main` and `/ (root)`, then Save.
4. Your site will be live at `https://<username>.github.io/<repo>/`.

## Customize
- Brand color: change `--g` in `styles.css`.
- Text and sections: edit `index.html`.
- Contact form: it is a demo. Connect it to Formspree or Netlify Forms.
