# Step 10 — two-week pilot in one clinic

## Before day 1 (one afternoon)
- [ ] Checklist rows 1–48 done with test data by one person.
- [ ] Backup workflow ran once and a restore drill passed. Privacy notice filled in and checked. 2FA on for every staff login.
- [ ] Admin > Settings: clinic name, public address. Doctors, departments, minutes per patient, beds and prices entered. Sample medicines reviewed or deleted by a pharmacist.
- [ ] Printer tested (slip and bill). Queue-board screen or TV on the waiting-room wall, opened to `…/app/#board` in full screen.
- [ ] **Paper stays as the backup for the whole pilot.** Staff write the paper record too. If the internet fails, nobody waits for the computer.
- [ ] One 30-minute training per role. Show only that role’s screens and the Feedback button.

## Daily (5 minutes, same person)
1. Admin > Feedback: read new items, mark Seen/Fixed. Fix the confusing ones the same day if small.
2. Admin > Reports (yesterday): visits, avg wait, unpaid. Compare with the paper count; write down any difference.
3. Admin > Messages: any failed? Admin > Privacy: any request open? 
4. Ask each role one question: “What slowed you down today?”

## What to measure (compare with how it was before)
| Measure | Where | Good sign |
|---|---|---|
| Average wait to first call | Reports | Falls, or stays level while queue is visible |
| Patients asking “how long?” at the desk | Tally sheet | Falls |
| Report turnaround | Reports | Stable or falling |
| Unpaid bills at end of day | Reports | Falls |
| Messages failed | Messages | Under 5 % |
| Staff feedback “broken” | Feedback | Falls week 1 → week 2 |
| Wrong/missing records vs paper | Daily check | Zero |

## Stop rules (pause and use paper only)
Any patient data shown to the wrong person; a wrong dispense or allergy miss; the system down for more than 30 minutes in clinic hours; or staff cannot keep up with paper alongside.

## Day 14: go / no-go
Go only if: no safety incidents, staff would choose to keep it, backups restore, and the fix list for “broken” items is empty.
Then grow one thing at a time: more doctors → SMS gateway live → pharmacy stock counts → wards → claims.
